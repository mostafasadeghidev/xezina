## چرا Xezina؟

صدها صفحه را ذخیره می‌کنید، بعد پیدایشان نمی‌کنید؛ و هر مرورگر هم مجموعهٔ جدای خودش را دارد.
Xezina هر دو مشکل را حل می‌کند:

- **یک مجموعه بوکمارک، همه‌جا.** Chrome، Edge، Brave، Opera، Vivaldi و Firefox همیشه یکسان می‌مانند.
- **کتابخانه‌ای که واقعاً می‌شود در آن جست‌وجو کرد.** یادداشت، برچسب، پیش‌نمایش و جست‌وجوی فوری در همه‌چیز.
- **بدون حساب کاربری، بدون سرورِ ما.** داده‌هایتان در فضای ابری یا سرورِ خودتان می‌ماند.

## نصب

1. آخرین فایلِ zip را از **[Releases](https://github.com/mostafasadeghidev/xezina/releases/latest)** دانلود کنید.
2. **Chrome، Edge، Brave، Opera، Vivaldi:** فایلِ `xezina-*-chrome.zip` را از حالتِ فشرده خارج کنید ← `chrome://extensions`
   را باز کنید (در Edge: `edge://extensions`) ← **Developer mode** (حالتِ توسعه‌دهنده) را روشن کنید ← **Load unpacked** ← پوشهٔ استخراج‌شده را انتخاب کنید.
3. **Firefox:** از `xezina-*-firefox.zip` استفاده کنید. نسخهٔ امضاشده در addons.mozilla.org منتشر خواهد شد.

پوشهٔ استخراج‌شده را جابه‌جا یا پاک نکنید؛ مرورگر افزونه را از همان‌جا بارگذاری می‌کند.

## شروع سریع

1. Xezina را با <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>B</kbd> باز کنید، یا روی آیکونِ آن در نوار ابزار و سپس دکمهٔ شبکه‌ای کلیک کنید.
2. به **تنظیمات ← همگام‌سازی** بروید، یک فضای ذخیره‌سازی انتخاب کنید و وصل شوید.
3. Xezina را در مرورگرهای دیگرتان هم نصب کنید و آن‌ها را به **همان فضای ذخیره‌سازی** وصل کنید.
   اگر از رمزنگاری استفاده می‌کنید، همان عبارتِ عبور را وارد کنید.
4. تمام. بوکمارک‌ها در نوار و منوی بوکمارکِ خودِ هر مرورگر نمایش داده می‌شوند. مدیرِ Xezina را
   فقط وقتی باز کنید که می‌خواهید جست‌وجو کنید، یادداشت بنویسید یا مرتب کنید.

> [!TIP]
> در دستگاه‌هایی که Xezina همگام‌سازی می‌کند، همگام‌سازیِ بوکمارکِ خودِ مرورگر را خاموش کنید (Chrome Sync برای بوکمارک‌ها،
> همگام‌سازیِ Favorites در Edge) تا دو سیستم هم‌زمان روی یک بوکمارک‌ها دست نبرند.

> [!NOTE]
> اولین باری که مرورگری وصل می‌شود، بوکمارک‌هایی که با بقیه مشترک دارد (همان پوشه، همان نشانی)
> با هم تطبیق داده می‌شوند و تکراری نمی‌شوند. اگر می‌خواهید مرورگری **دقیقاً** مثلِ نسخهٔ ابری شود،
> یک بار از **تنظیمات ← همگام‌سازی ← این مرورگر را مثل فضای ابری کن** استفاده کنید. پیش از آن یک پشتیبان گرفته می‌شود.

## همگام‌سازی چطور کار می‌کند

هر بوکمارک یک رکورد است که هر فیلدش یک مُهرِ زمانیِ hybrid logical clock دارد. هر دستگاه
نسخهٔ کاملِ ادغام‌شدهٔ خودش را در قالبِ یک فایل (`devices/<id>.xz`) بارگذاری می‌کند و فایل‌های دستگاه‌های
دیگر را می‌خواند. ادغام، تازه‌ترین مقدارِ هر فیلد را برمی‌دارد، پس نتیجه به ترتیبِ رسیدنِ فایل‌ها بستگی
ندارد (یک CRDT مبتنی بر حالت). چون هر دستگاه فقط فایلِ خودش را می‌نویسد، هر فضای ذخیره‌سازیِ سادهٔ فایلی
کار می‌کند و دو دستگاه هرگز روی کارِ هم نمی‌نویسند. موارد حذف‌شده به‌صورتِ tombstone نگه داشته می‌شوند؛ پوشه‌ای
که در یک دستگاه حذف شود ولی در دستگاهی دیگر بوکمارکِ تازه‌ای به آن اضافه شود، همراه با همان بوکمارک برمی‌گردد.
ترتیبِ داخلِ پوشه‌ها با fractional indexing تعیین می‌شود.

## توسعه

```bash
pnpm install
pnpm dev                 # Chrome with live reload  (pnpm dev:firefox for Firefox)
pnpm test                # unit tests + randomized multi-browser sync simulations
pnpm build && node scripts/e2e.mjs        # two real Edge profiles syncing over WebDAV
pnpm build && node scripts/screenshots.mjs  # regenerate docs/screenshots
pnpm zip && pnpm zip:firefox
```

| پوشه | محتوا |
|---|---|
| `src/core` | مدلِ داده، ادغامِ CRDT، ترتیب‌دهی، جست‌وجو |
| `src/sync` | خواندن و اعمالِ بوکمارک‌های مرورگر، تطبیق در اولین اتصال، رمزنگاری |
| `src/storage` | یک آداپتورِ کوچک برای هر فضای ذخیره‌سازی |
| `src/background` | زمان‌بند، پیش‌نمایش‌ها، بررسیِ پیوندها |
| `src/ui` | مدیر، پنجرهٔ بازشو (popup)، ترجمه‌ها (`src/ui/i18n`) |
| `docs` | وب‌سایت (GitHub Pages)، اسکرین‌شات‌ها، README‌های ترجمه‌شده |

**برنامه‌های ورود:** Google Drive، Dropbox، OneDrive و «Sign in with GitHub» به OAuth client id نیاز دارند
که هنگامِ build از `.env` خوانده می‌شود (`.env.example` را ببینید) یا کاربران خودشان در
**تنظیمات ← پیشرفته** واردش می‌کنند. راهنمای گام‌به‌گام: [docs/oauth-setup.md](../oauth-setup.md).

**ترجمه‌ها:** متن‌های رابط کاربری در `src/ui/i18n/<lang>.ts` و متن‌های وب‌سایت در
`docs/i18n/<lang>.js` هستند. اصلاحاتِ اهلِ زبان با کمالِ میل پذیرفته می‌شود.
